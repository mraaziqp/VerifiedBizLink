## 🚨 IF SOMETHING BREAKS

### Problem: Page won't load
**Solution:**
1. Refresh page (Ctrl+R)
2. Check: http://localhost:9002
3. If not running: Open terminal and run `npm run dev`

### Problem: Login fails
**Solution:**
1. Check email spelling
2. Verify password is: `password123`
3. Try different test account

### Problem: Feature doesn't work
**Solution:**
1. Skip it - say "in development"
2. Move to next demo point
3. Don't dwell on it

### Problem: Slow/Laggy
**Solution:**
1. Close other browser tabs
2. Refresh page
3. Restart browser if needed
