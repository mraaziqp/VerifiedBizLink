## 🚨 IF SOMETHING BREAKS

### Page Won't Load
```
What to do:
1. Refresh browser (Ctrl+R)
2. Wait 5 seconds
3. If still broken: "Let me restart the server quickly"
   - This is normal. Don't panic.
   - Restart takes 30 seconds
   - Continue demo when ready
```

### Button Doesn't Work
```
What to do:
1. Try clicking again
2. If still doesn't work: "Let me navigate there a different way"
3. Go to next feature
4. Don't apologize. Act like it's intentional.
```

### Can't Remember What to Say
```
What to do:
1. Take a breath
2. Look at your script (if visible)
3. Or paraphrase: "This is where businesses upload documents"
4. Keep going
5. You know this - you practiced it
```

### They Ask Something You Don't Know
```
What to do:
1. Say: "That's a great question. Let me add that to our roadmap."
2. Or: "Let me verify that and get back to you."
3. Don't make up answers
4. Be honest
5. Move forward
```
