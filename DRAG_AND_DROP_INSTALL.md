## 🎯 **Super Easy 5-Step Installation**

### **Step 1: Enable Unknown Sources (30 seconds)**

On your **Android phone:**

```
1. Open Settings app

2. Scroll to "Security" or "Privacy"

3. Find "Unknown Sources"

4. Toggle it ON
   (You'll see a warning - tap OK)

5. Done! ✓
```

**Visual Guide:**
```
Settings
  ├─ Security
  │   └─ Unknown Sources → Toggle ON
  └─ Privacy
      └─ Unknown Sources → Toggle ON
```

---

### **Step 2: Connect Phone to Computer (30 seconds)**

```
1. Use USB cable (comes with phone)

2. Plug into phone and computer

3. On phone: A notification appears
   "USB connected"

4. Tap the notification

5. Select "File Transfer" mode
   (NOT "Charge only")

6. Done! ✓
```

---

### **Step 3: Find the APK File on Computer (30 seconds)**

**Open File Explorer:**

```
1. Press Windows key + E (opens File Explorer)

2. Navigate to:
   This PC → K: drive (if visible)
   OR
   k:\Projects\VerifiedBizLink\android\app\build\outputs\apk\release\

3. You'll see: app-release-unsigned.apk (9.4 MB)

4. Done! ✓
```

**Or copy the path into address bar:**
```
k:\Projects\VerifiedBizLink\android\app\build\outputs\apk\release\
```

---

### **Step 4: Copy APK to Phone (1 minute)**

**In File Explorer:**

```
1. Right-click on: app-release-unsigned.apk

2. Select: Copy

3. On left sidebar, find your phone
   (Usually shows as "Mohammed's S23 FE" or similar)

4. Double-click to open phone storage

5. Navigate to: Downloads folder
   (Or any accessible folder)

6. Right-click → Paste

7. Wait for file to copy (usually 10-30 seconds)

8. Done! ✓
```

**OR DRAG & DROP:**
```
1. Keep APK file window open

2. Open phone storage window side-by-side

3. Drag app-release-unsigned.apk 
   → Drop into Downloads folder

4. Done! ✓
```

---

### **Step 5: Install on Phone (1 minute)**

**On your phone:**

```
1. Open File Manager app
   (Usually pre-installed)

2. Navigate to Downloads folder

3. Look for: app-release-unsigned.apk

4. Tap on it
   (It will show the APK icon)

5. Tap "Install"

6. Wait for installation (usually 10-20 seconds)

7. You'll see "App installed successfully" ✓

8. Tap "Open" to launch app
   OR
   Tap "Done" and find icon on home screen

9. Done! 🎉
```

## ⚠️ **If Installation Fails**

### **Error: "Unknown error"**
```
1. File might be corrupted
2. Delete the APK from phone
3. Copy fresh APK again
4. Try installing again
```

### **Error: "App not installed"**
```
1. Not enough storage
2. Delete some files to free space
3. Try again
```

### **Error: "Cannot find file"**
```
1. File didn't copy to phone
2. Check Downloads folder
3. Copy file again
```

### **Phone doesn't show as storage**
```
1. Try different USB port on computer
2. Try different USB cable
3. Restart phone and computer
4. Try again
```
